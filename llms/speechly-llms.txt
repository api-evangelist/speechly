# Speechly

> Speechly was a real-time spoken language understanding (SLU) and streaming speech recognition API, including audio/text moderation, from a Finnish startup acquired by Roblox. The standalone product and hosted API have been DISCONTINUED; open-source client SDKs and gRPC/protobuf API definitions remain publicly available in the archived github.com/speechly organization. This llms.txt is generated by the API Evangelist enrichment pipeline from the catalog and retained artifacts.

## Status

- Company: acquired by Roblox; product discontinued.
- Website: https://speechly.com (301 redirects to https://roblox.com)
- GitHub organization: https://github.com/speechly (archived 2025-01-07)
- Hosted API (api.speechly.com / docs.speechly.com): no longer resolves.
